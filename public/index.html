新增帳號

登入 deepai.org 後按 F12 → Network → 隨便點一個 api.deepai.org 的請求 → Request Headers → 找到 cookie: → 複製整行值貼到下面。多個帳號可一行一個。
之後對話會自動輪流用池內的帳號(session),配額耗盡自動冷卻換下一個。

直接填 deepai.org 的 Email 與密碼,閘道會用官網同款登入流程(/daily-time-sync/login/)自動登入並保管 session;cookie 過期自動重登。
